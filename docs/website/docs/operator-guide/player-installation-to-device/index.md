# Player Installation to Device

This section covers operator-side installation of device players onto supported target devices.

On Meta Quest and METALENSE 2, the easiest way is the QAROS Visualizer's **Devices** tab: it finds or downloads `adb`, installs or updates the player over USB, and puts METALENSE 2 glasses on Wi-Fi. Each device page describes that first and the manual `adb` steps second.

## Device pages

- [HoloLens 2](/docs/operator-guide/player-installation-to-device/hololens-2) - sideload the QAROS HoloLens Player through the Device Portal.
- [Meta Quest](/docs/operator-guide/player-installation-to-device/meta-quest) - install the Quest APK with ADB after enabling Developer Mode.
- [P&C Solutions METALENSE 2](/docs/operator-guide/player-installation-to-device/metalense-2) - install the METALENSE 2 APK with ADB.
